About

Eastbound Reports provides daily summaries of Russian media coverage, automatically generated from major Russian news sources including TASS, RT, Sputnik, Interfax, and RIAN.

Each day, we fetch the latest articles and use AI to distill the main themes into 1-2 sentences, giving you a quick snapshot of what Russian media is focusing on.

Summaries are posted daily to Twitter/X and LinkedIn.

How It Works

  • Automated RSS feed monitoring of 5 major Russian news sources
  • Full article content extraction (not just headlines)
  • AI-powered summarization using Claude Code
  • Daily posting to social media
  • 100% open source

Open Source

All code is available on GitHub. Feel free to fork, contribute, or use for your own projects.
